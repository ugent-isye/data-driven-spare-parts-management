****************************
DATA-DRIVEN SPARE PARTS MANAGEMENT
****************************

This repository provides the complete implementation, data, and simulation environment used to study the integration of machine degradation information into spare parts ordering decisions under stochastic lead times and batch ordering constraints.


Contact name	Naim Al Khoury ( naim.alkhoury@UGent.be )
Authors		Naim Al Khoury ( naim.alkhoury@UGent.be ), Zaharah Bukhsh ( z.bukhsh@tue.nl ), Dieter Claeys ( dieter.claeys@ugent.be )
ZAP name	Dieter Claeys ( dieter.claeys@ugent.be )
Website		( https://github.com/ugent-isye/data-driven-spare-parts-management )


-------------------------------------------------------------------------------

1. ABSTRACT
-----------

A framework for developing spare parts control policies by leveraging degradation data.
The environment is built as an OpenAI environment, and policies can be developed and benchmarked.



2. SOFTWARE DEPENDENCIES
------------------------

Programming Language:
- Python 3.7 or higher (recommended: Python 3.9+)

Core Python Packages:
- see requirements.txt

Installation:
Install all required packages using the provided requirements.txt file:
pip install -r requirements.txt


The software was developed and tested with Python 3.9+ and the latest stable versions of the aforementioned packages as of December 2025.

4. GETTING STARTED
------------------

INSTALLATION:

1. Clone the repository:
   git clone https://github.com/ugent-isye/data-driven-spare-parts-management.git
   cd data-driven-spare-parts-management

2. Create a virtual environment (recommended):
   python -m venv venv
   source venv/bin/activate
   (On Windows: venv\Scripts\activate)

3. Install dependencies:
   pip install -r requirements.txt

4. Launch Jupyter Notebook:
   jupyter notebook

5. Check the main.ipynb notebook for a preview on how to use the various algorithms
